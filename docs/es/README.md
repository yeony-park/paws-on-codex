# Paws on Codex 🐾

[English](../../README.md) · [한국어](../ko/README.md) · [日本語](../ja/README.md) · [简体中文](../zh-CN/README.md) · **Español** · [Deutsch](../de/README.md) · [हिन्दी](../hi/README.md) · [Français](../fr/README.md) · [Português](../pt-BR/README.md) · [Русский](../ru/README.md)

Mascotas de Codex en 3D, con estética de mascota virtual retro, que conservan los rasgos reconocibles del animal real. El proyecto nació porque quería tener versiones 3D de mis propios compañeros, Chapssari y Mandu.

<p align="center"><img src="../../previews/comparison.png" alt="Chapssari y Mandu" width="800"></p>

## Instalación rápida

```bash
curl -fsSL https://raw.githubusercontent.com/yeony-park/paws-on-codex/main/install.sh | bash -s -- chapssari
curl -fsSL https://raw.githubusercontent.com/yeony-park/paws-on-codex/main/install.sh | bash -s -- mandu
```

La ruta predeterminada es `~/.codex/pets/<pet-name>/`. Reinicia o actualiza Codex después de instalar.

## Comunidad

Añade una presentación de una sola línea, con un máximo de 180 caracteres, en `community-pets/github-id--pet-name.md`. Puedes subir una foto con el mismo nombre base a `community-pets/photos-inbox/`; tras la fusión se eliminarán los metadatos, se redimensionará, se convertirá a WebP y se actualizará la [galería](../../community-pets/GALLERY.md). Consulta [CONTRIBUTING.md](../../CONTRIBUTING.md).

Usa `$create-companion-pet` en Codex para crear desde fotos un paquete v2 validado y otro v1 para la web.
