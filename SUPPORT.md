# Support

Use the repository's [issue forms](https://github.com/yeony-park/paws-on-codex/issues/new/choose):

- choose **Bug report** for installation, rendering, MCP, or animation problems;
- choose **Feature request** for new behavior or platform support;
- choose **Pet contribution** when introducing a companion.

Do not include API keys, tokens, private prompts, private repository contents, or unredacted personal information. Security-sensitive reports should describe only the minimum reproducible details and ask the maintainer for a private follow-up channel.
