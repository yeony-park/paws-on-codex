# Privacy Policy

Effective date: August 17, 2026

Paws on Codex is a read-only virtual-pet plugin operated by Yeony Park. It lists published pet characters and displays a selected animation.

## Data handled

The plugin processes the pet identifier and animation name supplied in a tool call. The application does not request accounts, contacts, files, precise location, payment information, or advertising identifiers. Application logs record only request method, route, response status, duration, and server errors; they do not intentionally record prompt text, tool arguments, IP addresses, or sprite contents. The hosting provider may process ordinary network metadata such as IP addresses under its own policy.

## Purpose and sharing

Data is used only to return the requested pet, operate the service, diagnose failures, and protect reliability. Paws on Codex does not sell personal data or use it for advertising. Infrastructure providers receive only the data necessary to host and deliver the service.

## Retention and controls

Application logs are retained for no more than 30 days in production unless a longer period is required to investigate abuse or comply with law. The plugin stores no user profile. You may stop processing by disconnecting or uninstalling the plugin. Questions or deletion requests can be filed through [Paws on Codex support](https://github.com/yeony-park/paws-on-codex/issues/new/choose).

## Companion contributions

Photos and introductions submitted to this repository are handled under [CONTRIBUTING.md](CONTRIBUTING.md). Public pet assets are included in the plugin only when their contributor explicitly opts in.

Material changes to this policy will be published in this repository with a new effective date.
