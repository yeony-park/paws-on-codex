# Community companions

Add one `github-id--pet-name.md` file with a single 180-character introduction. You may also submit one matching JPG, PNG, or WebP photo to `photos-inbox/`; automation publishes a metadata-free, resized WebP in `photos/` and updates [GALLERY.md](GALLERY.md).

```markdown
**Name** · species/breed · [@github-id](https://github.com/github-id) — A warm one-line introduction.
```

Read [`CONTRIBUTING.md`](../CONTRIBUTING.md) before submitting photographs or installable assets.
